# Delta Espaço e Eventos 🏛️✨

Plataforma web institucional, comercial e interativa para o **Delta Espaço e Eventos** — o principal espaço para casamentos, formaturas, aniversários de 15 anos e eventos corporativos em Bacabal - MA.

Desenvolvido com arquitetura moderna em **React 19**, **TypeScript**, **Tailwind CSS** e **Vite**, projetado para alta conversão comercial, excelente performance e experiência fluida em dispositivos móveis e desktop.

---

## 🌟 Principais Funcionalidades

- **Apresentação do Espaço:** Visão panorâmica dos ambientes, climatização, camarins e pista de dança.
- **Diferenciais e Estrutura:** Capacidade para até 600 convidados, gerador próprio de energia e estacionamento monitorado.
- **Gastronomia e Buffet:** Cardápios refinados para casamentos, coquetéis corporativos, coffee breaks e estações temáticas.
- **Galeria Interativa (Lightbox):** Visualização em alta definição com suporte a navegação por teclado e gestos de swipe em mobile.
- **Simulador de Orçamento em Tempo Real:** Cálculo interativo com estimativa de convidados, serviços inclusos e geração automática de mensagem formatada para WhatsApp.
- **Integração WhatsApp Direta:** Botões estratégicos com mensagens contextuais pré-configuradas.
- **Localização e Mapa:** Endereço completo em Bacabal - MA com rotas diretas via Google Maps e Waze.
- **FAQ Interativo:** Respostas claras para as principais dúvidas dos clientes.
- **SEO & Performance:** Metatags completas (OpenGraph, Twitter Cards, dados estruturados JSON-LD `EventVenue` para o Google).

## 🛠️ Tecnologias Utilizadas

- **Frontend:** [React 19](https://react.dev/) + [TypeScript](https://www.typescriptlang.org/)
- **Estilização:** [Tailwind CSS 4](https://tailwindcss.com/)
- **Ícones:** [Lucide React](https://lucide.dev/)
- **Build Tool:** [Vite](https://vitejs.dev/)
- **Deploy:** Otimizado para [Vercel](https://vercel.com/) com suporte a SPA rewrites (`vercel.json`).

## 🚀 Como Executar Localmente

### Pré-requisitos
- Node.js (v18 ou superior recomendado)
- npm, yarn ou pnpm

### Passos
1. Clone o repositório:
   ```bash
   git clone https://github.com/renanpvp84-source/DELTA-ESPA-O-E-EVENTOS.git
   cd DELTA-ESPA-O-E-EVENTOS
   ```

2. Instale as dependências:
   ```bash
   npm install
   ```

3. Inicie o servidor de desenvolvimento:
   ```bash
   npm run dev
   ```

4. Abra no navegador:
   ```
   http://localhost:3000
   ```

## 📦 Build para Produção

Para gerar os arquivos otimizados para produção:
```bash
npm run build
```

Para validar a tipagem TypeScript:
```bash
npm run lint
```

---

## 🌐 Publicação na Vercel

1. Acesse [Vercel Dashboard](https://vercel.com).
2. Clique em **Add New...** > **Project**.
3. Importe o repositório `renanpvp84-source/DELTA-ESPA-O-E-EVENTOS`.
4. As configurações padrão do Vite já serão detectadas automaticamente:
   - **Framework:** Vite
   - **Build Command:** `npm run build`
   - **Output Directory:** `dist`
5. Clique em **Deploy**!
